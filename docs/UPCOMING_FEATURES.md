# Upcoming Features

This file tracks planned product and platform capabilities that are not yet complete.

## Identity and Security

- BYOK (Bring Your Own Key) support for provider credentials and encryption key rotation.
- MFA (multi-factor authentication) for account sign-in and sensitive profile changes.
- Session management UI (active sessions, revoke devices, anomaly alerts).

## AI and Product Experience

- Chat with AI assistant for recipes, substitutions, and meal-plan questions.
- AI memory controls to tune personalization per user.
- Safer AI fallback routing with provider health scoring and circuit breaking.

## Infrastructure and Operations

- Blue/green release workflow with health-gated cutover.
- Automated backup verification and restore drills.
- Per-environment observability dashboards and alert thresholds.
